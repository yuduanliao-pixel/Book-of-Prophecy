## 2. 整體流程（Pipeline）

```
使用者輸入問事內容
  │
  ▼
[A] 問題精練與用神判定 ──不合格──► 反問補充
  │ 合格
  ▼
[B] 取當下時間 → 換算年月日時干支、定月令、定旬空
  │
  ▼
[C] 隨機起卦（3 枚銅錢 × 6 輪，由下而上；字/背數值法）
  │
  ▼
[D] 卦象推導（本卦→變卦→互卦→錯卦→綜卦）
  │
  ▼
[E] 京房裝卦（定宮→世應→納甲納支→五行→六親→六獸→伏神→旬空標註）
  │
  ▼
[F] 斷卦（用神→月令旺衰→日辰→月破→動變/回頭生剋/進退神→世應→輔助卦/六獸）
  │
  ▼
[G] 輸出排盤 + 結合問題的白話解說
```

> 離線執行檔（§13）只跑 B、C、D、E、G 之排盤部分，**不含** A（精練）與 F（斷卦）與結論。

## 3. 階段 A：問題精練（Question Refinement）

### 3.1 處理規則
1. **去情緒**：移除抱怨、形容詞堆疊，只留事實與訴求。
2. **去模糊**：須含「主體＋事項＋時間範圍（可選）」，且一卦只問一事。
3. **單一化**：一次多問請擇一或拆多卦。
4. **判定用神**（供階段 F）：

| 問題類別 | 用神 | 範例 |
|---|---|---|
| 求財、生意、投資 | 妻財爻 | 此筆投資可獲利否 |
| 求職、官司、疾病、（女占）夫 | 官鬼爻 | 面試能否錄取 |
| 文書、合約、考試、房產、長輩、（占）父母 | 父母爻 | 合約能否簽成 |
| 子女、晚輩、平安、醫藥 | 子孫爻 | 孩子此行平安否 |
| 兄弟朋友、合夥、競爭對手 | 兄弟爻 | 與友合夥可行否 |
| **占自身整體吉凶（無法歸類）** | **世爻** | 我今年運勢如何 |

### 3.2 反問條件（不起卦，先澄清，一次一問）
- 純情緒宣洩、無可占之「事」。
- 主體不明（占自己？占他人？）。
- 一句含兩件以上互斥之事。
- 問題無法對應任何用神類別且非「占自身」。

### 3.3 倫理約束
- 涉自傷、傷人、重大醫療決策：不起卦，回應關懷並建議專業協助。
- 固定附註：占卜結果僅供參考與自省，不構成醫療、法律、投資建議。

## 4. 階段 B：時間換算（干支、月令、旬空）

### 4.1 取時規則
- 以**起卦當下**系統時間為準（需時區；預設 Asia/Taipei）。
- 換算四柱：年、月、日、時干支。

### 4.2 換算要點

| 柱 | 規則 |
|---|---|
| 年柱 | 以**立春**交節為界換年（非農曆正月初一） |
| 月柱 | 以**節（十二節氣）**為界：立春→寅、驚蟄→卯、清明→辰、立夏→巳、芒種→午、小暑→未、立秋→申、白露→酉、寒露→戌、立冬→亥、大雪→子、小寒→丑。月干以「五虎遁」由年干推 |
| 日柱 | **基準 2000-01-01 = 戊午（干支序 54，0-based）**；等價錨點 2000-01-07 = 甲子。以該日做 mod 60 推算。換日策略見 `day_boundary_policy` |
| 時柱 | 兩小時一支（23–01 子時…）；時干以「五鼠遁」由日干推 |

> **C1 修正**：v0.1 之「2000-01-01 = 甲辰」為錯誤，凡引用處全部更正為「戊午」。
> **換日參數** `day_boundary_policy`：
> - `zi_initial_23`（預設，從俗）：23:00 起即視為次日干支。
> - `midnight_00`：00:00 才換日干支。
> - `split_zi`（傳統晚子時）：日干支仍用當日，但 23:00–24:00 標為「夜子時」，時干仍依當日日干。
> 三者皆須在 SKILL.md 與執行檔輸出中明示採用何派。

> **節氣計算（C5）**：以天文演算法即時計算 24 節氣（太陽視黃經每 15° 一節氣），實作於 `engine/solar_terms.py`（Meeus 太陽位置 + ΔT + 時區，精度約 ±1–2 分鐘，涵蓋約 1900–2100），完全離線。`references/solar_terms_*.csv` 僅作驗證對照與「近年權威值覆蓋」之用（落在表內則優先採權威值）。

### 4.3 月令五行與旺相休囚死
- 地支五行：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土。
- **月令 ＝ 月建（以節氣定之月支）之地支五行**，為全卦旺衰最高權重：

| 關係 | 狀態 |
|---|---|
| 爻五行＝月令 | 旺 |
| 月令生爻 | 相 |
| 爻生月令 | 休 |
| 爻剋月令 | 囚 |
| 月令剋爻 | 死 |

- **日辰（日支）**為第二權重：生扶、剋制、沖（六沖）、合（六合）皆判。
- **月破（C3）**：爻支被月建所沖即月破（六沖：子午、丑未、寅申、卯酉、辰戌、巳亥）；用神月破多主失令受傷，動爻/出月/合破/實破時另論。

### 4.4 旬空（空亡，C3）
- 依**日柱所屬旬**定兩空支：

| 旬（日柱起） | 旬空 |
|---|---|
| 甲子旬（甲子…癸酉） | 戌、亥 |
| 甲戌旬（甲戌…癸未） | 申、酉 |
| 甲申旬（甲申…癸巳） | 午、未 |
| 甲午旬（甲午…癸卯） | 辰、巳 |
| 甲辰旬（甲辰…癸丑） | 寅、卯 |
| 甲寅旬（甲寅…癸亥） | 子、丑 |

- 卦中爻支逢空支即標「空」。用神空亡須綜合旺衰、動靜、日月生扶、出空填實判斷，不可一律作無。

## 5. 階段 C：起卦演算法

### 5.1 隨機源
- **必須**使用密碼學等級隨機（Python `secrets`），禁止 LLM 自行「腦補」擲幣結果。
- 每枚錢二態，機率各 50%。

### 5.2 成爻規則（一輪擲 3 枚銅錢，字/背數值法 — C2）

| 錢面 | 數值 | 陰陽 |
|---|---:|---|
| 字面（有文字面） | 2 | 陰 |
| 背面（無字／花面） | 3 | 陽 |

| 三錢總和 | 組合 | 爻名 | 記號 | 動爻？ | 變卦作 |
|---:|---|---|---|---|---|
| 6 | 三字 | 老陰（交 ✕） | ▅▅　▅▅ | **是** | 變**陽** |
| 7 | 兩字一背 | 少陽 | ▅▅▅▅▅ | 否 | 陽 |
| 8 | 一字兩背 | 少陰 | ▅▅　▅▅ | 否 | 陰 |
| 9 | 三背 | 老陽（重 ○） | ▅▅▅▅▅ | **是** | 變**陰** |

- 四象機率：少陽=少陰=3/8、老陽=老陰=1/8。
- **現代硬幣對應**：若以現代硬幣起卦，必須先明定「哪一面＝字、哪一面＝背」，再套上表；本系統內部一律以「字/背」為準並於輸出附圖例，杜絕「正/反」歧義。
- **手動輸入**（執行檔功能）：使用者逐爻輸入三枚錢面（字/背），引擎以同表成爻。

### 5.3 成卦順序
- 連續六輪，**由下往上**：第 1 輪＝初爻（最底）→ 第 6 輪＝上爻（最頂）。
- 資料結構：`lines = [初, 二, 三, 四, 五, 上]`，每元素 `{coins:["背","字","背"], sum:8, yinyang, moving}`。
- 輸出排盤須**反向列印**（上爻在最上），並逐爻顯示三枚錢面明細，確保過程可驗證。

## 6. 階段 D：卦象推導

設本卦六爻（自下而上）為 `L1..L6`：

| 卦 | 定義 | 演算法 | 斷卦權重 |
|---|---|---|---|
| 本卦 | 起卦原貌 | 少陽/老陽→陽，少陰/老陰→陰 | 主軸 |
| 變卦 | 動爻變化後之卦 | 老陽→陰、老陰→陽，靜爻不變；無動爻則無變卦，註「六爻安靜」 | 主軸（論結局） |
| 互卦 | 事情中間過程 | 下卦取 `L2,L3,L4`、上卦取 `L3,L4,L5` | **輔助敘事** |
| 錯卦 | 對立面、旁通 | 六爻全部陰陽互換 | **輔助敘事** |
| 綜卦（原需求「總卦」） | 換位觀點 | 六爻上下顛倒 | **輔助敘事** |

> **C4**：互/錯/綜僅作敘事補充，**不得**覆蓋納甲六親＋月令日辰動變之主要吉凶。每卦均需解析卦名（64 卦）與上下經卦名。

## 8. 階段 F：斷卦邏輯（推理規格）

斷卦結論依下列優先序組裝，且每步在輸出中可追溯：

1. **取用神**：依 §3.1 類別取（占自身取世爻）；不上卦則取伏神並降權，論飛伏。
2. **月令定旺衰**：用神對月令論旺相休囚死（§4.3），為吉凶基調。
3. **日辰修正**：生扶／剋制／沖（暗動、日破）／合（合住、合起）。
4. **月破/旬空**：月破論失令受傷（待出月、合破、實破另論）；旬空論待時填實。
5. **動爻與動變**：動爻剋生用神權重最高；看化出之爻——**回頭生**、化**進神**為吉，**回頭剋**、化**退神**、化破、化空為凶。
6. **世應關係**：世為己、應為彼，論生剋合沖判雙方態勢。
7. **特殊卦象**：六沖卦（八純卦＋無妄、大壯等）多主散/不成或速；六合卦多主成/和；六沖變六合先難後易，反之先易後難——作態勢輔助。
8. **六獸取象**：僅敘事輔助（青龍喜慶、朱雀口舌文書、勾陳遲滯田土、螣蛇怪異纏繞、白虎疾病刑傷、玄武暗昧盜失），**不得**單獨改變吉凶。
9. **輔助卦參照**：互卦論過程、變卦論結局、錯卦論對立、綜卦論換位——僅敘事補充。
10. **應期（可選）**：依用神旺衰與沖合給概略應期（如逢申酉月日），語氣保留。

> 防呆：禁止絕對化斷語（「必死」「絕對成功」）；以「偏吉／吉中帶阻／偏凶／凶中有救」分級，並回扣原問題給可行動建議。

## 9. 階段 G：輸出格式（範本）

```
【占問】占：Q3 轉職面試能否錄取？（用神：官鬼爻）

## 12. 驗收測試（最小集，已以實證錨點更新）

1. `cast`：跑 ≥100,000 次，四象分布接近理論（少陽=少陰≈3/8、老陽=老陰≈1/8，容差 ±1%）。
2. `ganzhi` 日柱錨點：**2000-01-07 = 甲子**、**2026-06-13 = 戊午**、2000-01-01 = 戊午 全對。
3. `ganzhi` 節氣/月柱：對 2026 立春 02-04 04:03、芒種 06-05 23:40 等交節前後一分鐘，月柱換算正確（容差以權威表 ±2 分鐘）。
4. `ganzhi` 旬空：戊午日 → 旬空子丑；甲子日 → 戌亥；驗六旬全對。
5. `zhuanggua`：天風姤（乾宮一世，世初應四，外卦壬午申戌、內卦辛丑亥酉…）與另一權威排盤工具比對全對；64 卦定宮/世應/六親全對。
6. 變卦/伏神：姤之二爻動變天山遯；用神不上卦時伏神取本宮首卦同位，正確。
7. 模糊問題（「我好煩」）觸發反問而非起卦（skill 層）。
8. 端到端：輸入具體問題，輸出含 §9 全部欄位且斷語回扣原問題（skill 層）。
9. 執行檔（§13）：四種輸入模式皆能產生 §13.4 完整輸出，且不含精練/斷卦/結論。

## 13. 離線排盤執行檔規格（新交付物）

### 13.1 目標與邊界
- **目標**：可離線、雙擊執行的單一 Windows `.exe`（PyInstaller onefile），僅做「起卦＋裝卦＋排盤顯示」。
- **明確不含**：問題精煉（A）、斷卦推理（F）、結論。純呈現排盤事實。
- **依賴**：僅 Python 標準庫 + 本專案 engine；隨機用 `secrets`；節氣用內建演算法。無網路、無外部 API。

### 13.2 輸入模式（四項，對應使用者需求）
1. **互動輸入占問**：啟動後提示「請輸入占問：」，將原句顯示於【占問】。
2. **自動系統時間起卦**（預設）：取當下系統時間換算干支。
3. **可手動指定時間**：提供選項輸入 `YYYY-MM-DD HH:MM`（補卦/回測）；未輸入則用系統時間。
4. **可手動輸入銅錢結果**：選擇「自動擲幣（CSPRNG）」或「手動逐爻輸入三枚錢面（字/背）」。
- 介面採選單式互動；亦支援命令列參數（`--question`、`--time`、`--manual`、`--boundary`）供進階/自動化。

### 13.3 必含輸出欄位
1. **【占問】**：使用者輸入原句。
2. **【起卦時間】**：地方時 + 時區 + 換日策略 → 年月日時四柱干支 + 月令（含節氣別）+ 旬空。
3. **【擲幣過程】（由下而上）**：逐爻三枚錢面（字/背）+ 總和 + 爻名 + 動靜，附「字=2陰／背=3背」圖例。
4. **【卦象】（條列式）**：本卦／變卦／互卦／錯卦／綜卦，含宮、宮五行、世代、上下經卦。
5. **【裝卦表】**：由上而下列每爻：爻位、六獸、伏神(若有)、六親、納甲、納支(五行)、本卦記號、世/應、動、變爻(六親)、旬空標記。

### 13.4 建議追加之補充欄位（執行檔加值）
- **世應標示行**：明列世爻、應爻位置與其六親。
- **用神候選**：依占問類別自動標出可能用神所臨之爻（僅標示，不斷吉凶）。
- **動爻摘要**：列出動爻與其變化（化進/化退/回頭生剋之「事實標記」，不下結論）。
- **旬空/月破/日辰關係**：純事實標記每爻是否逢空、是否月破、與日辰之沖合。
- **干支全息**：年月日時四柱完整、節氣交節時刻、農曆日期（可選）。
- **可重現性**：輸出本次擲幣的隨機摘要（如各爻錢面序列）與版本號，便於存檔比對。
- **匯出**：可選將排盤存成 `.txt` / `.json`（供日後交給 skill 做斷卦）。

### 13.5 非功能需求
- 終端中文顯示（UTF-8；Windows 主控台自動設定 codepage / 字型容錯）。
- 單檔啟動 < 3 秒；無需安裝。
- 例外處理：時間格式錯、手動錢面輸入非法（非字/背或非三枚）須友善提示重輸。
- 版本與免責資訊固定顯示於頁尾。

## 14. 邊界情況

| 情況 | 處理 |
|---|---|
| 六爻安靜（無動爻） | 無變卦；以本卦世爻或用神靜斷，註「以靜制動」 |
| 六爻亂動（≥4 動爻） | 註卦象動盪，斷語保守，建議擇日再占 |
| 用神兩現 | 取臨世應、臨動爻、不空不破或旺者，輸出取捨理由 |
| 用神不上卦 | 查伏神，論飛伏，吉凶降一級表述 |
| 用神旬空/月破 | 標記並依出空填實、出月實破論待時 |
| 同事重占 | 提醒「再三瀆，瀆則不告」，建議間隔或換角度 |
| 無法取得時區 | 詢問所在地，預設 Asia/Taipei |
| 節氣/換日邊界 | 明示採用之 `day_boundary_policy` 與節氣時刻來源 |
