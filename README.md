# 窺天鏡 Book of Prophecy — 京房納甲六爻卜卦

> Skill 識別名：`jingfang-liuyao`

以京房納甲六爻（文王卦）體系打造的卜卦工具，提供兩種前端：

1. **Claude Skill** — 在 Claude 中完成「問題精練 → 起卦 → 裝卦 → 斷卦解說」全流程。
2. **離線排盤執行檔** — 單一 `.exe`，離線、雙擊即用，只做「起卦 + 裝卦 + 排盤顯示」，不含斷卦。

v1.1.0 起另附**命盤排盤**（八字、紫微斗數），可在 skill 中與六爻合參；同樣是純標準庫、離線、只輸出排盤事實。

> 體系依據：《增刪卜易》《卜筮正宗》《火珠林》。所有起卦/裝卦規則均經 **獨立雙重網路查證**（Claude + codex）後定稿，並以單元測試對權威萬年曆與排盤驗證。

## 特色

- **確定性引擎 + 彈性解說分離**：隨機與查表交給可驗證的純函式引擎；取象與斷卦解說交給 LLM。
- **密碼學等級亂數**：擲幣使用 `secrets`，杜絕「腦補」結果。
- **天文節氣計算**：以截斷式 VSOP87 即時計算 24 節氣（精度約 ±1–2 分鐘，對照 timeanddate 天文金標準），完全離線、支援寬廣年份。
- **完整裝卦**：八宮世應、納甲納支、六親、六獸、伏神、旬空、月破、進退神、回頭生剋、互/錯/綜/變卦。
- **學派可設定**：換日策略（子初 23 時 / 子正 00 時 / 夜子時分日）可選。
- **伏吟、反吟標記**：動爻化出地支不變或相沖時，逐爻與內外卦都會標出。
- **命盤合參**：八字（四柱、十神、藏干、十二長生、納音、大運、流年）與紫微斗數（十二宮、十四主星、十四輔星、亮度、四化、大限、流年），對照開源排盤庫各數千例驗證。

## 重要的考據修正

- **日柱基準**：常見錯誤「2000-01-01 = 甲辰」，正確為 **2000-01-01 = 戊午**（乾淨錨點 2000-01-07 = 甲子）。雙方獨立查證一致，並以萬年曆與今日干支交叉驗證。
- **擲幣語義**：採火珠林計數法「字面 = 2（陰）、背面 = 3（陽）」，避免「正/反」歧義。1背=少陽、2背=少陰、3背=老陽、0背=老陰。

## 使用方式一：Claude Skill

將本 repo 放入 Claude Code 的 skills 目錄（或作為 plugin），即可由「卜一卦／占卜／起卦／六爻」等語境觸發。流程見 [SKILL.md](SKILL.md)。

## 使用方式二：離線排盤執行檔

下載 `jingfang-liuyao-paipan.exe`（見 GitHub Releases，或自行建置），雙擊執行進入互動選單：

1. 輸入占問
2. 選擇起卦時間（系統時間 / 手動指定）
3. 選擇換日策略
4. 選擇起卦方式（自動擲幣 / 手動輸入錢面）
5. （可選）選擇占問類別以標示用神候選

也支援命令列：

```powershell
# 自動擲幣、系統時間
jingfang-liuyao-paipan.exe -q "面試能否錄取" -c "求職/官司/疾病/功名"

# 指定時間 + 手動錢面（由下而上，每組三枚；字=2陰、背=3陽）
jingfang-liuyao-paipan.exe -q "面試" -t "2026-06-13 14:32" -m "背背字;背背背;背字字;背字字;背字字;背字字"

# 輸出 JSON（可交給 skill 做斷卦）
jingfang-liuyao-paipan.exe -q "今日運勢" --no-interactive -e json
```

輸出包含：占問、起卦時間（天干地支、月令、旬空、節氣）、擲幣過程（由下而上）、卦象（條列）、裝卦表（由上而下，含六獸/伏神/六親/納甲/旺衰/世應/動/變爻/旬空月破），以及世應、動爻摘要、日辰關係等補充。**不含斷卦與結論。**

## 使用方式三：命盤排盤（八字／紫微斗數）

```bash
# 八字＋紫微，列出 2026–2029 流年，文字輸出
python scripts/mingpan.py --birth "1990-05-15 08:30" --gender 女 --years 2026-2029 --format text

# 只排八字，輸出 JSON（交給 skill 合參）
python scripts/mingpan.py -b "1990-05-15 08:30" -g 女 -s bazi
```

- 輸入為**西曆、出生地民用時**；時區以 `--tz` 指定（預設 UTC+8）。未校正真太陽時。
- 晚子時（23 時）沿用 `--boundary` 換日策略；紫微閏月預設十五日前歸本月、十六日起歸下月（`--no-fix-leap` 可改為一律歸本月）。
- 紫微支援農曆 1900–2100 年，排十四主星與十四輔星，不含雜曜、小限、流月。
- 輸出只有命盤事實，**不含格局、喜忌與吉凶判斷**。合參規則見 [SKILL.md](SKILL.md)。

離線執行檔（`app/paipan.py`）只做六爻，不含命盤。

## 從原始碼建置執行檔

需要一個安裝了 PyInstaller 的 Python（建議 3.11）：

```powershell
pip install pyinstaller
# 在 repo 根目錄
powershell -ExecutionPolicy Bypass -File build/build_exe.ps1
# 產物：dist/jingfang-liuyao-paipan.exe
```

## 開發與測試

引擎僅用標準庫，任何 Python 3.8+ 皆可：

```bash
python tests/test_engine.py        # 六爻引擎
python tests/test_mingpan.py       # 農曆／八字／紫微
python -m pytest                   # 全部
```

測試涵蓋：日柱錨點、立春換年/換月邊界、換日策略、旬空、八宮 64 卦唯一性、天風姤完整裝卦與伏神、互錯綜變、伏吟反吟、擲幣機率分布、字背計數法；農曆換算往返、閏月；八字十神、長生、納音、大運順逆與對照案例；紫微安星、四化、亮度、大限流年、晚子時、閏月與對照案例。

`references/solar_terms_2020_2040.csv` 可覆蓋特定節氣權威時刻；未列入的節氣會自動回落到內建天文演算法。
